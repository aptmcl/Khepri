Khepri

An algorithmic design tool that integrates design, analysis, and optimization. The same program produces an equivalent design in every backend — only the using line changes.

Core

  • KhepriBaseGeometry, materials, levels and families, and the backend protocol.
  • KhepriUmbrella entry point for Khepri users.

CAD and BIM

  • KhepriAutoCADAutoCAD, over a C# plugin.
  • KhepriRevitAutodesk Revit, over a C# plugin.
  • KhepriRhinoRhinoceros 3D, over a C# plugin.
  • KhepriGrasshopperGrasshopper, Rhino's visual programming environment.

Rendering and visualization

  • KhepriBlenderBlender, over a Python plugin.
  • KhepriUnityThe Unity engine, over a C# plugin.
  • KhepriUnrealUnreal Engine, over a C++ plugin.
  • KhepriPOVRayRay-traced rendering via POV-Ray.
  • KhepriThreejs3D visualization in the browser via Three.js.
  • KhepriTikZTikZ output for standalone figures and LaTeX documents.
  • KhepriThebesPure-Julia SVG rendering, built on Thebes.jl and Luxor.jl.

Analysis and tools

  • KhepriFrame4DDStructural analysis, built on Frame4DD.
  • KhepriLibraryReusable parametric building components.
  • KhepriIllustratorStep-by-step visual tracing of a Khepri program's evaluation.
Source at github.com/aptmcl/Khepri. Frame4DD and KhepriSVG ship in the repository but publish no documentation site. MIT licensed.
